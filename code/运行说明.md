## 二、数据

- `data/`：BioSNAP random / unseen_drug / unseen_target + BindingDB random 的 train/val/test CSV（**与仓库逐字节一致，MD5 已验证**）。
- 划分说明：BioSNAP 去重 7 对后 27,457；7:1:2；冷启动按 canonical SMILES / 标准化蛋白分组，三 split 实体交集=0（无泄漏）。BindingDB 无重复对。
- **子图缓存（28GB，不在交付包内）**：首次运行前必须重建：

```bash
python build_subgraph_cache.py --data biosnap --split random --hop 2
python build_subgraph_cache.py --data biosnap --split unseen_drug --hop 2
python build_subgraph_cache.py --data biosnap --split unseen_target --hop 2
python build_subgraph_cache.py --data bindingdb --split random --hop 2
```

## 三、运行命令（env `sgbandti`）

### 3.1 主实验
```bash
# BioSNAP random 5 种子（论文主表）
python main.py --data biosnap --split random --hop 2 --seeds 42,52,62,72,82
# 结果: result/biosnap_random_hop2/seed_summary_stats.csv (0.9062±0.0019)

# BindingDB random 5 种子（SGBANDTI 目前只有 seed42=0.9613，需补满）
python main.py --data bindingdb --split random --hop 2 --seeds 42,52,62,72,82

# 冷启动 5 种子（目前 seed42 已完成，需补满）
python main.py --data biosnap --split unseen_drug --hop 2 --seeds 42,52,62,72,82
python main.py --data biosnap --split unseen_target --hop 2 --seeds 42,52,62,72,82
```

**⚠️ 论文注意事项**：
1. 论文旧值多处不可复现（BioSNAP 0.8987→新 0.9062；冷启动 unseen_target 0.843→新 0.623），**必须用本交付包的新数字**。
2. DrugBAN 全面 ≥ SGBANDTI（见汇总第五节核心结论）——论文定位需相应调整，不可宣称"优于最强基线"。
3. GraphBAN 是 transductive 口径，与 random 不可直接比。
