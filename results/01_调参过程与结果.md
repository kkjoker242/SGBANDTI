# SGBANDTI 超参微调全记录（论文"超参设置/验证"节可用）

> 时间：2026-08-18 晚 — 08-19。目的：在定版模型上系统检验超参（正规化/注意力头/学习率/宽度/批大小/epoch/调度），判断是否有配置能在验证集上超过定版。
> **红线**：全部**验证集选优，绝不看 test 挑配置**；一次一个变量（批次内除外）；架构零改动。

## 一、总结论

**7 个变体中仅"MAX_EPOCH=250"单种子胜出（best val AUROC 0.9132，+0.0071），其余 6 个均未超过定版（best val AUROC 0.9061）。因 5 种子确认未做（实验室按 150ep 复现 abl_full 0.9056 与定版打平），定版模型维持（BioSNAP 0.9062 / 150ep）。**

| 批次 | 变体 | best val AUROC | Δ vs 0.9061 | 判定 |
|------|------|---------------|------------|------|
| 1 | dropout 0.2 + weight_decay 1e-4 | 0.8906 | -0.0155 | ❌ 更差，放弃 |
| 2 | BAN heads 2→4 | 0.9063 | +0.0002 | 打平，不换（慢70%） |
| 4 | lr 5e-5→1e-4 | 0.9043 | -0.0018 | ❌ 更差 |
| 4 | hidden 128→256（drug+protein） | 0.9028 | -0.0033 | ❌ 更差 |
| 5 | batch_size 64→32 | 0.9062 | +0.0001 | 打平 |
| 5 | lr 1e-4 + cosine 调度 | 0.9027 | -0.0034 | ❌ 更差 |
| 5 | **MAX_EPOCH 150→250** | **0.9132** | **+0.0071** | ✅ 单种子胜出（5 种子未确认） |

**证据信号**：正则化（dropout+wd）→ 变差 = 模型未过拟合；容量（hidden256）→ 变差 = 模型未欠拟合。**唯一例外**：更久训练（MAX_EPOCH=250）在单种子显著提升（+7.1 点，best epoch 231，印证"模型没跑够"），但 5 种子层面未确认，定版仍维持 150ep。

## 二、方法论（保证结论可信）

1. **单种子 42 便宜筛**（噪声 ±0.001-0.002；超过才叫"更差/胜出"，之内叫"打平"）。
2. **全部验证集选优**，best val AUROC 为判据；test 仅作参考，绝不用于挑配置。
3. **一次一个变量**（批次内除外）；所有变体 = 同一模型的不同配置，架构零改动。
4. **输出隔离**：`--tag` 把每次跑写入独立目录 `result/biosnap_random_hop2_<tag>/seed_42/`，不覆盖官方 `result/biosnap_random_hop2/`。
5. **默认行为逐位可复现**：所有新旋钮默认关闭（dropout=0/weight_decay=0/cosine=off/max_epoch=150/batch=64/heads=2/lr=5e-5/hidden=128），官方 0.9062 不受影响。

## 三、关键 Bug 修复（必须写进代码可复现说明）

**`nn.Dropout(p=0.0)` 在 p=0 时仍消耗 RNG**（污染 DataLoader shuffle → 默认配置回归跑 0.9027 ≠ 官方 0.9061）。
修复：`MLPDecoder` 加 `self.use_drop = dropout > 0` 门控，p=0 时完全跳过原版前向 3 行。
**验证**：p=0 不耗 RNG、p=0.2 正常耗；默认配置逐位可复现官方 0.9061。
> 论文 Methods 若提到 dropout，可注明"训练时 dropout p=0 为恒等、不影响推理与默认设置"。

## 四、代码改动（全部已实现于 code/ 交付代码）

| 文件 | 改动 | 用途 |
|------|------|------|
| configs.py | 新增 `DECODER.DROPOUT=0.0`、`SOLVER.WEIGHT_DECAY=0.0`、`SOLVER.COSINE=False` | 旋钮默认关闭 |

**运行示例**（env `sgbandti`，Python 3.10）：
```bash
python main.py --data biosnap --split random --hop 2 --seeds 42 --tag tune_baseline
python main.py --data biosnap --split random --hop 2 --seeds 42 --dropout 0.2 --weight-decay 1e-4 --tag tune_dropout02_wd1e4
python main.py --data biosnap --split random --hop 2 --seeds 42 --heads 4 --tag tune_heads4
python main.py --data biosnap --split random --hop 2 --seeds 42 --lr 1e-4 --tag tune_lr1e4
python main.py --data biosnap --split random --hop 2 --seeds 42 --hidden 256 --tag tune_hidden256
python main.py --data biosnap --split random --hop 2 --seeds 42 --batch-size 32 --tag tune_bs32
python main.py --data biosnap --split random --hop 2 --seeds 42 --lr 1e-4 --cosine --tag tune_cosine
python main.py --data biosnap --split random --hop 2 --seeds 42 --max-epoch 250 --tag tune_maxepoch250
```
自动链脚本：`code/run_hypertune_overnight.sh`、`code/run_hypertune_batch4.sh`、`code/run_hypertune_knobs.sh`；报告脚本 `code/make_tune_report.py`。

## 五、各批次明细

### 批次1（正则化）—— ❌
- dropout 0.2（MLP 三层后）+ Adam weight_decay 1e-4。
- 结果：val 0.8906（-1.5 点）。正则化不帮忙（模型未过拟合）。
- 附带发现并修复 RNG bug（见上）。

### 批次2（BAN heads）—— 打平
- `BCN.HEADS` 2→4。结果：val 0.9063（+0.0002，噪声内）。每 epoch 慢 ~70%，不划算。

### 批次4（lr / hidden）—— ❌ / ❌
- lr 1e-4：val 0.9043（-1.8 点）。
- hidden 256（drug+protein 128→256，参数 1.07M→2.32M）：val 0.9028（-3.3 点，过拟合更重）。

### 批次5（bs / cosine / epoch）—— ✅ 完成
- **batch_size 32**：val 0.9062（打平）。
- **lr 1e-4 + cosine**：val 0.9027（更差）。
- **MAX_EPOCH 250**：val **0.9132**（+0.0071，**唯一胜出变体**；best epoch 231，印证"模型没跑够"）。单种子胜出但 5 种子未确认（实验室按 150ep 跑 abl_full 0.9056 与定版打平）→ **定版维持 150ep**。详见 `00_实验结果汇总.md` 第三节调参总表。
